# 🛒 SupermarketPOS

سیستم مدیریت فروشگاه (Point of Sale) سبک، سریع و کاملاً آفلاین برای سوپرمارکت‌ها و فروشگاه‌های کوچک تا متوسط.

طراحی‌شده با تمرکز روی **سرعت کار صندوق**، **رابط فارسی** و **استفاده بدون نیاز به سرور**.

---

## ✨ ویژگی‌ها

- **صندوق فروش (POS)**
  - افزودن کالا با بارکد (پشتیبانی از بارکدخوان)
  - مدیریت سبد خرید
  - کنترل موجودی لحظه‌ای
  - ثبت فروش و کسر خودکار موجودی

- **مدیریت کالاها**
  - افزودن، ویرایش و حذف محصولات
  - جستجو بر اساس نام، بارکد و دسته‌بندی
  - مدیریت قیمت و موجودی

- **گزارش‌ها**
  - فروش امروز
  - مجموع فروش
  - کالاهای پرفروش
  - لیست آخرین فروش‌ها

- **سایر قابلیت‌ها**
  - ذخیره‌سازی محلی با IndexedDB (کاملاً آفلاین)
  - رابط کاربری مدرن و موبایل‌فرندلی
  - پشتیبانی کامل از زبان فارسی و راست‌چین (RTL)
  - فرمت اعداد فارسی

---

## 🛠 تکنولوژی‌ها

- HTML5
- CSS3 (طراحی مدرن و ریسپانسیو)
- Vanilla JavaScript (ES Modules)
- IndexedDB (پایگاه داده سمت کلاینت)

بدون هیچ فریمورک سنگینی. سبک، سریع و قابل اعتماد.
